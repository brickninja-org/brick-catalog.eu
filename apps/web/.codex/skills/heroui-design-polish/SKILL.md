# HeroUI Design Polish Skill

Use this skill after implementing features to improve perceived quality.

## Polish Checklist

1. Visual hierarchy
- Clear headline/subheadline scale
- Consistent spacing rhythm
- Strong contrast for key actions

2. Component consistency
- Button variants are intentional
- Card surfaces/borders match section purpose
- Input states are consistent (default/hover/focus/error)

3. Motion and feedback
- Subtle, meaningful transitions
- Loading/skeleton states for async sections
- Empty states with useful copy

4. Responsive quality
- No cramped controls on mobile
- Table/content overflow handled gracefully
- Sticky/TOC/progress elements do not overlap content

5. Accessibility
- Focus visibility across interactive components
- Keyboard operability
- Adequate color contrast

## Output

Return a short list:
- issues found
- exact component/file touched
- impact on UX
